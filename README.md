# Endoriano.github.io
SITO DI EDOARDO VILLANI
                                                                                          PROGETTO

Gli obiettivi principali del progetto sono la catalogazione, la metadatazione, la preservazione e la valorizzazione delle opere giovanili del periodo napoletano di Boccaccio, evidenziando il suo primo pensiero e l'ambiente storico-culturale nel quale si è formato.
in particolare si vuole mostrare, oltre alle 4 opere scritte da Boccaccio durante la residenza napoletana, i luoghi, i personaggi e le personalità che hanno contribuito a formare il pensiero e il percorso artistico dell'autore nella sua prima giovinezza.
Nel sito è presente una pagina con una mappa di Napoli in cui è possibile cliccare gli edifici archittettonici legati all'autore toscano per approfondimenti.
Tra i file principali, oltre a quattro pagine .html si annoverano file di dataset degli item, di metadatazione ed analisi in XML (con DC, DCTERMS e TEI), nonché immagini necessarie al layout del sito.
